# Wine Classifier
Trains, evaluates and compares 3 classification models (Decision Tree Classifier, Linear Regression, KNeighbors Classifier) to determine which best predicts the class of a wine from given data
Comparison is done based on accuracy scores and confusion matrices for each model

# Fish Weight Predictor
Trains, evaluates and compares a linear regression model and a Decision Tree Regressor model to determine which is best to predict the weight of a fish based on its length, including a comparison of R² scores and residuals analysis
To use this code yourselves, please download the fish.csv file and update the file path in the code
