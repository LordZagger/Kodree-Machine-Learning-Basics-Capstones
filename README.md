# Wine Classifier
Trains, evaluates and compares 3 scikit-learn classification models (Decision Tree Classifier, Linear Regression, KNeighbors Classifier) to determine which best predicts the class of a wine from given data
Comparison is done based on accuracy scores and confusion matrices for each model

# California Housing Predictor
Trains and evaluates a scikit-learn Linear Regression model to predict the prices of California houses based on given data
Includes plots of predicted vs actual values and residuals

# Fish Weight Predictor
Trains, evaluates and compares a scikit-learn linear regression model and a scitkit-learn Decision Tree Regressor model to determine which is best to predict the weight of a fish based on its length
Comparison uses R² scores, plots of predicted vs actual and residuals
To use this code yourselves, please download the fish.csv file and update the file path in the code
